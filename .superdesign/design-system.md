# Nous AI Academy public-site direction

## Product

Nous AI Academy is a Windows desktop, offline-first technical AI library. The public site should make the value proposition unmistakable: five intensive AI books and twenty focused technical files are packaged in the desktop application, readable and downloadable locally, with private on-device progress.

## Brand

- Use the supplied Nous book-and-circuit logo exactly in the navigation and any logo position. Never replace it with initials, emoji, generic AI icons, or an invented SVG.
- Maintain the visible name **Nous AI Academy**.
- Use `Outfit` for display headlines, `Inter` for UI/body, and `JetBrains Mono` only for data labels and technical metadata.

## Orange system

- Ink: `#211812`
- Espresso: `#34241B`
- Orange: `#E95C24`
- Deep orange: `#B83A16`
- Amber: `#F5A524`
- Cream canvas: `#FFF8F2`
- Paper: `#FFFFFF`
- Line: `#E9D8CC`
- Muted text: `#76685F`
- Success: `#23835B`

Use orange purposefully for calls to action, active navigation, key metrics, and small technical highlights. Avoid purple, cyan, neon gradients, fake glassmorphism, and decorative math symbols. Preserve substantial contrast and keyboard focus visibility.

## Layout and tone

- Desktop-first, editorial and technical—not a generic AI landing page.
- Calm cream canvas, crisp white surfaces, dark ink typography, strong orange CTA hierarchy.
- Use a disciplined 12-column desktop grid, generous 24–96 px vertical rhythm, and 12–20 px corner radii.
- Replace floating decorative elements with meaningful product proof: library counts, offline operation, document previews, Windows installation, and local-first privacy.
- Motion is short and restrained; honour `prefers-reduced-motion`.

## Required landing-page content

1. Header: real logo, Books, Intensive Files, Offline Reader, FAQ, and Download for Windows.
2. Hero: clear offline-library message, primary download action, proof points, and a refined application/library visual.
3. Evidence strip: 5 core books, 20 intensive files, 1,750 validated pages, offline access.
4. Library section: book and intensive-file preview cards that look like real publications.
5. Product workflow: install, open, read/download, resume locally.
6. Privacy and technical section: packaged PDFs, local reader, search, bookmarks, and preserved local progress.
7. FAQ, concise footer, accessible responsive behavior.
