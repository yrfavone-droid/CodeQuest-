# Shared components

The public site is a single static document (`index.html`) with no reusable framework component directory. Its reusable visual primitives are CSS classes rather than source components: `.btn`, `.nav-link`, `.hero-badge`, `.architecture-node`, `.feature-card`, `.stat-card`, `.faq-item`, and footer link groups.

The exact implementation lives in `index.html` and `styles.css`; no independently exported UI component source exists to duplicate here.
