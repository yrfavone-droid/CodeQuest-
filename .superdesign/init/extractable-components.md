# Extractable components

The public site is static HTML, so there are no framework components to convert. The following patterns are deliberately left inline for this first landing-page redesign:

- Navigation bar — `index.html`, layout pattern; logo and download CTA.
- Button variants — `styles.css`, basic pattern; primary and secondary CTAs.
- Content cards — `styles.css`, basic pattern; feature, statistics, and FAQ states.
- Footer — `index.html`, layout pattern; informational navigation.

No component extraction is required before creating a design draft.
