# Routes

| URL | Source | Layout |
| --- | --- | --- |
| `/` | `index.html` | Single public Nous AI Academy landing page |
| `/api/download?os=windows` | `server/server.js` | Download redirect endpoint, not a visual route |
| `/health` | `server/server.js` | JSON health endpoint, not a visual route |

The landing page anchors are `#path`, `#features`, `#stats`, `#release`, `#faq`, and `#team`.
