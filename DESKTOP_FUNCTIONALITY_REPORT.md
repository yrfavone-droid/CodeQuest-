# CodeQuest Academy desktop functionality report

Validated after the local-account migration. The desktop application now provides Create Account,
Sign In, legacy credential setup, Profile editing, Change Password, and Sign Out. All account and
learning data remains local to the device.

## Local account behavior

- First launch routes to Create Account when no profiles exist.
- Existing profiles without an active session route to Sign In.
- A valid active session opens Dashboard on restart.
- Signed-out users cannot access Dashboard or Profile through authentication routes.
- Sign Out clears only ActiveSession and preserves all progress, projects, mastery, attempts, and
  activity.
- Multiple profiles are keyed by local user ID and normalized case-insensitive email.

## Security

Passwords use PBKDF2-HMAC-SHA256 with a unique 16-byte salt, 210,000 iterations, and 256-bit keys.
Only the encoded hash, salt, algorithm, and parameters are stored. Password verification uses
constant-time comparison. No browser or external authentication provider is used.
