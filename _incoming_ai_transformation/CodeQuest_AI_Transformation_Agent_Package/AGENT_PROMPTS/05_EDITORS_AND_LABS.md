# Prompt 05 - Build Editors and Labs

Implement a production Python editor, Math Lab, Algorithm Visualizer, and ML Lab. Use isolated execution, strict time/memory/network limits, safe package allowlists, cancellation, quotas, deterministic tests, and observable job states. Never execute learner code in the main application process. Save real files, attempts, outputs, and versions. Provide accessible keyboard controls, mobile fallbacks, and clear errors. Do not display simulated terminal or model results.
