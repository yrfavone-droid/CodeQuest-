# Prompt 10 - Test Migrate and Deploy

Create a staging clone or safe migration rehearsal. Back up data, run additive migrations, validate row counts and sample user progress, test rollback, and compare analytics. Run lint, typecheck, unit, integration, end-to-end, accessibility, security, performance, production build, and mobile viewport checks. Deploy behind feature flags or a staged rollout. Monitor authentication, progress sync, editor jobs, errors, and content defects. Do not expose secrets or run a destructive production command.
