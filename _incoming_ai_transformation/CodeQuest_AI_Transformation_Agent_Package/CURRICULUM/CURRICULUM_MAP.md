# CodeQuest AI Academy Curriculum Map

The core path is English-only and progresses from zero prior experience to deployable AI projects. Existing coding content should be audited and reused where it supports Python, algorithms, web demos, or computational thinking. Do not delete legacy content during migration.

## T01 - AI Orientation and Computational Thinking (400 problems)

Outcome: Explain core AI ideas, decompose problems, and identify responsible uses before writing models.

Modules:
1. What AI Can and Cannot Do
2. Data Models and Algorithms
3. Problem Decomposition
4. Logic Patterns and Pseudocode
5. Responsible AI Foundations

## T02 - Python for AI (1400 problems)

Outcome: Write, test, debug, and organize Python programs used in data and AI workflows.

Modules:
1. Syntax Variables and Types
2. Conditions Loops and Functions
3. Collections and Comprehensions
4. Files Exceptions and Modules
5. Object-Oriented Python
6. Testing Debugging and Complexity
7. NumPy Foundations
8. Python Projects for Data and AI

## T03 - Algorithms and Data Structures (1000 problems)

Outcome: Select and implement efficient structures and algorithms, then justify complexity tradeoffs.

Modules:
1. Complexity and Big O
2. Arrays Strings Stacks and Queues
3. Hash Tables Sets and Heaps
4. Linked Structures Trees and Graphs
5. Sorting Searching and Recursion
6. Greedy Dynamic Programming and Backtracking
7. Graph Algorithms
8. Interview and AI Pipeline Problems

## T04 - Mathematics for AI (1800 problems)

Outcome: Use the mathematical language required to understand, implement, and diagnose learning algorithms.

Modules:
1. Arithmetic Algebra and Functions
2. Vectors Matrices and Linear Systems
3. Linear Transformations and Eigen Concepts
4. Probability Rules and Random Variables
5. Statistics Estimation and Sampling
6. Derivatives Gradients and Partial Derivatives
7. Optimization and Gradient Descent
8. Information Theory and Numerical Stability

## T05 - Data Skills (800 problems)

Outcome: Transform raw data into documented, reproducible, model-ready datasets.

Modules:
1. NumPy Arrays and Vectorization
2. Pandas Tables and Joins
3. SQL for Analysis
4. Cleaning Missing Values and Outliers
5. Exploratory Data Analysis
6. Visualization and Communication
7. Feature Engineering and Data Leakage

## T06 - Machine Learning Foundations (1600 problems)

Outcome: Build and evaluate classical ML systems without data leakage and with appropriate baselines.

Modules:
1. ML Workflow and Baselines
2. Linear and Polynomial Regression
3. Logistic Regression
4. K-Nearest Neighbors and Naive Bayes
5. Decision Trees and Random Forests
6. Support Vector Machines
7. Clustering and Dimensionality Reduction
8. Metrics Validation and Imbalanced Data
9. Pipelines Tuning and Interpretation

## T07 - Advanced Machine Learning (700 problems)

Outcome: Compare advanced methods, tune them responsibly, and reason about uncertainty and failure modes.

Modules:
1. Boosting Bagging and Stacking
2. Regularization and Generalization
3. Probabilistic Models
4. Anomaly Detection and Recommenders
5. Time Series Forecasting
6. Causal Thinking and Experiment Design

## T08 - Deep Learning (1100 problems)

Outcome: Implement, train, diagnose, and compare neural models while controlling compute and overfitting.

Modules:
1. Perceptrons and Neural Networks
2. Forward Pass Loss and Backpropagation
3. Optimization Initialization and Normalization
4. Convolutional Neural Networks
5. Sequence Models and Attention
6. Transformers
7. Autoencoders and Generative Models
8. PyTorch Training and Debugging

## T09 - Natural Language Processing and LLMs (500 problems)

Outcome: Build and evaluate practical language systems without confusing fluent output with correctness.

Modules:
1. Text Processing and Classical NLP
2. Embeddings and Semantic Search
3. Transformers and Language Modeling
4. Prompting Structured Output and Tools
5. Retrieval-Augmented Generation
6. LLM Evaluation Safety and Cost

## T10 - Computer Vision (300 problems)

Outcome: Prepare image data, train vision models, and evaluate performance across relevant groups and conditions.

Modules:
1. Image Representation and Augmentation
2. Classification with CNNs
3. Detection Segmentation and Transfer Learning
4. Vision Evaluation and Bias

## T11 - Reinforcement Learning (200 problems)

Outcome: Model sequential decisions and explain the tradeoff between exploration, reward, and safety.

Modules:
1. Agents Environments Rewards and Policies
2. Bandits and Exploration
3. Markov Decision Processes
4. Q-Learning and Policy Gradients

## T12 - MLOps Responsible AI and Capstones (200 problems)

Outcome: Ship documented AI systems with monitoring, risk controls, reproducible experiments, and honest claims.

Modules:
1. Reproducibility Versioning and Experiment Tracking
2. Serving Monitoring and Drift
3. Privacy Fairness Security and Documentation
4. Portfolio Capstone Planning

## Core progression rule

A learner completes a node by reaching mastery, not by clicking through. Each node requires instruction, guided practice, independent practice, a mastery check, and spaced review. Projects unlock only after prerequisite skills are mastered.
