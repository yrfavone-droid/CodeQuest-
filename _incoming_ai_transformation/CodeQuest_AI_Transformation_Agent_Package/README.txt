CODEQUEST AI TRANSFORMATION - AGENT HANDOFF PACKAGE

Purpose
This package is the complete instruction and production blueprint to give a coding/content agent before it transforms the existing CodeQuest Academy repository into CodeQuest AI Academy.

Start
1. Give the agent MASTER_AGENT_PROMPT.md.
2. Attach this entire package or make it available in the repository.
3. Tell the agent to follow AGENT_RUN_ORDER.txt.
4. Require it to stop after the audit for your approval before broad code changes.

Important distinction
- problem_manifest_10000.csv contains exactly 10,000 planned production slots. It is not 10,000 finished problems.
- The five book files are exact 100-page production blueprints and prompts. They are not the final authored 500 pages.
- The 20 deep-dive files are complete authoring briefs and prompts. They are not falsely labeled as published resources.

This is intentional: a reliable curriculum needs staged generation, automated validation, technical review, editorial review, pilot feedback, and versioned publishing. The included prompts instruct the agent to complete that work without fake data or unsupported completion claims.
