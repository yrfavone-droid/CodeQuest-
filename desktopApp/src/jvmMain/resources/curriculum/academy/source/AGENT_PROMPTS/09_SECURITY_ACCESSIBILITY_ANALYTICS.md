# Prompt 09 - Security Accessibility and Analytics

Threat-model authentication, content administration, code execution, file uploads, tutor prompts, learner data, APIs, rate limits, and dependencies. Enforce least privilege and row-level authorization or equivalent. Test WCAG 2.2 AA, keyboard use, focus, screen-reader names, color contrast, reduced motion, and editor accessibility. Define event schemas for real actions only; prohibit fake counters. Add privacy-aware retention, consent where needed, error monitoring, content-defect monitoring, and audit logs.
