# Screen Requirements

## Global navigation

Home, Learn, Practice, Labs, Projects, Books, Knowledge, Progress, Profile. Admin and Content Studio are permission-gated.

## Home

Continue learning, daily goal, streak, current mastery, recommended review, weak skills, recent projects, downloads, and honest activity history. Counts change only when real persisted events occur.

## Learn path

Vertical skill path grouped into worlds and units. Each node displays title, mastery, estimated time, prerequisites, and state. Checkpoints contain cumulative assessments and projects.

## Lesson

Desktop may use concept/content, workspace, and tutor/context panels. Mobile uses focused steps. Every lesson supports notes, bookmarks, report-content issue, progressive hints, keyboard navigation, and resume position.

## Practice

Quick review, weak skills, mistakes, math drills, code debugging, algorithms, ML analysis, and custom sessions. Show why an item was selected.

## Labs

Python Editor, Math Lab, Algorithm Visualizer, ML Lab, and guided notebooks. Save real work and execution output. Never show pretend terminal output.

## Books

Five books displayed with completion, chapters, bookmarks, download, search, and resume. Reading view includes table of contents, typography controls, note/highlight tools, and references.

## Knowledge

Twenty deep dives remain optional and visually distinct from the required path. Each shows prerequisites, depth, estimated time, downloadable PDF/text, and related core objectives.

## Progress

Track mastery, objective heatmap, retention, review queue, attempts, hint dependency, project rubric scores, and exportable transcript. Avoid a single vanity percentage.

## Content Studio

Structured editors for lessons, problems, test cases, books, and deep dives. Include preview, schema validation, automated QA, reviewer assignment, publication states, version diff, and rollback.
