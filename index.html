FAQ

What happens when I click Download?

Your browser downloads the official Windows installer. After it finishes, run Nous-AI-Academy-Setup-1.6.9.exe and follow the setup window. Chrome can show an uncommon-download warning for new unsigned .exe files; choose Keep after confirming the source is this official HTTPS site.

Are the books and Intensive Files really offline?

Yes. All 25 PDFs are bundled with the desktop application. The site only distributes the installer; it does not host the study PDFs individually.

What happens to my existing local data during an update?

Your local accounts, preferences, notes, bookmarks, reading progress, and last-opened pages are preserved. Removing the app does not intentionally remove that local reader data.

Why might Windows show a publisher notice?

The current installer is not code-signed. The installer checksum is published by the release endpoint; code signing is a separate future security improvement.

Can I remove the desktop app?

Yes. Use Windows Settings → Installed apps → Nous AI Academy, or run the installed “Uninstall Nous AI Academy” program.
